# Stag — Release notes

## 1.0.0 (initial release)

- Full Online Store 2.0 template set: home, product, collection, list
  collections, cart (page + drawer), search with predictive overlay, blog,
  article, pages (contact, FAQ, size guide, shipping), 404, gift card,
  password.
- Card-based cart drawer: spend-milestone offers bar, coupon field with
  applied-state feedback, gift option and order note (cart attributes),
  price details, product recommendations, sticky checkout footer.
- Color-aware product gallery: media tied to a color variant shows only when
  that color is selected; sticky cross-fade layout with thumbnail rail.
- Availability-aware variant pills, size-chart dialog, sticky add-to-bag bar
  on mobile.
- Editorial homepage sections: hero carousel, video gallery, category tiles,
  featured collection (grid + editorial), image with text (+ stats),
  testimonials, reviews carousel, FAQ, ticker, countdown, newsletter + popup.
- Localization: country/currency and language selectors; all copy
  translatable; image focal points respected across cropped imagery.
- Direct social sharing on product pages (Facebook, X, Pinterest, WhatsApp,
  copy link).
- Motion system with scroll reveals; every animation honors
  prefers-reduced-motion; all key flows work without JavaScript.
